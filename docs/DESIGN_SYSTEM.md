# SAYN — Mandatory Design System & UI Rules

## 1. Design Vision
Design SAYN as an Apple-inspired AI communication product: minimal, sophisticated, calm, precise, and native-feeling.

## 2. Strictly Prohibited Elements
1. **NO EMOJI ICONS**:
   - Never use emojis as interface icons (`🎤`, `✨`, `🚀`, `📝`, `⚙️`, etc.).
   - Use Lucide vector icons exclusively with consistent 16-20px sizing and optical alignment.
2. **NO PURPLE-THEMED UI**:
   - Purple must not be used as the primary accent, secondary accent, gradient color, background, glowing effect, or decorative highlight.
   - Strictly no purple-to-blue neon gradients, purple cards, or purple glassmorphism.
3. **NO GENERIC AI CLICHÉS**:
   - No floating random decorative orbs, neon glowing borders, excessive bouncing animations, or AI sparkles on every button.
